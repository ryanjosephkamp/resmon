# `docs/` — the published site, and the documents it publishes

Two things live here, and knowing which is which is the whole of this file.

**Markdown sources, edited by hand.** These are the files the repository itself links to by
path, so they stay where they are:

- `*.md` — the reference documents: `source-landscape.md`, `backup.md`,
  `local-api-security.md`, `adding-a-source.md` and the rest.
- `api-contract/*.md` and `api-contract/openapi.json` — the API contracts.
  `mcp.md` and the five feature contracts are written by hand. `openapi.json` and `http.md`
  are **generated and guarded:** `implementation_scripts/api_contract.py` writes them from the
  running FastAPI application, and `verification_scripts/test_api_contract.py` regenerates both
  and fails on any difference. Never edit those two by hand; regenerate with
  `python -m implementation_scripts.api_contract --write` from `resmon_scripts/`.

**Everything else here is build output** — `index.html`, the per-page directories,
`static/`, `screenshots/`, `404.html`, `.nojekyll`. It is generated by the Astro site in
[`../site/`](../site/) and committed, because GitHub Pages publishes this folder directly
rather than building anything. Do not edit it; edit the site and rebuild.

```bash
cd site
npm ci               # first time only
npm run build        # astro build, then copies the output in here
npm run verify       # checks the built output
```

`site/scripts/sync-docs.mjs` is what copies the output in. It deletes the previous build and
leaves the Markdown sources above untouched; its `PROTECTED` list is the authority on which
files are which.

## Publishing

GitHub Pages serves this folder at <https://ryanjosephkamp.github.io/resmon/>:
**Settings → Pages → Source = "Deploy from a branch", Branch = `main`, Folder = `/docs`.**
There is no workflow; a push to `main` that changes this folder republishes it within about a
minute.

`.nojekyll` stops GitHub running Jekyll over the built files. It is written by every build.
