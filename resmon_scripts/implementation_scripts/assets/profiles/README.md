# Starter watch profiles

A small curated set, shipped so that the Profiles page is not empty on a fresh
install and so there is something to try a *Watch* routine against without first
hunting down an identifier.

**Every profile here carries an ORCID that was verified**, not copied. Each
`cited` field records the check: `GET https://pub.orcid.org/v3.0/<id>/person` on
2026-09-06 returned the name the profile claims. A starter set whose identifiers
were pasted from somewhere would be teaching the wrong lesson on the first
screen — the whole point of the `cited` field is that an identifier nobody can
trace is an assertion.

**One candidate was dropped for exactly that reason.** Barend Mons's ORCID
record has no public name, so the check could not confirm it, and an unverifiable
identifier does not belong in a set held up as the example.

**People only, for now.** Institution profiles need affiliation matching, which
is 2.1b: shipping them here would put profiles in the picker that no routine mode
can yet use.

These are examples, not endorsements, and they are yours to edit or delete —
importing one copies it into your own database, after which it is a profile like
any other.
